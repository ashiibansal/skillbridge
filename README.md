# SkillBridge

## SkillBridge – A Skill Gap Analysis and Learning Resource Recommendation Platform for Students

SkillBridge is a web-based platform designed to help students identify gaps between their current skill sets and the skills required for their target career roles. The system analyzes user-provided skill data, highlights missing or weak skills, and recommends relevant learning resources to support informed, self-paced career preparation.

This project is developed using **Agile (Scrum) methodology** as part of an academic coursework, with iterative development across multiple sprints.

---

## 🚀 Features

- User registration and login
- Career role selection
- Role-based skill framework
- Skill self-assessment
- Skill gap analysis and visualization
- Personalized skill-focused roadmap
- Relevant learning resource recommendations
- Resource search and filtering
- Manual progress tracking
- Responsive web interface

## 🧩 Project Methodology

The project follows **Agile Scrum methodology**, with development divided into multiple sprints:

- Sprint 1: Project setup, authentication, core UI
- Sprint 2: Career roles and skill framework
- Sprint 3: Skill gap analysis
- Sprint 4: Personalized roadmap and resource linking
- Sprint 5: Progress tracking, testing, and refinement

Agile practices such as sprint planning, daily stand-ups, sprint reviews, and retrospectives are followed throughout the project lifecycle.

## 🎯 Project Objective

The objective of SkillBridge is to provide students with a centralized platform that:
	•	Clarifies career skill requirements
	•	Identifies individual skill gaps
	•	Recommends relevant learning resources
	•	Supports structured and informed career planning
